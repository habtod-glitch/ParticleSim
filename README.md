# Particle Simulator

Решил сделать симулятор частиц на C++ с Win32 API. Без движков, без библиотек — только то, что в Windows уже есть.

## Что это

Окно на весь экран, внутри летают шарики. У них есть гравитация, они отскакивают от стен и от красных кубов. Постепенно теряют скорость и останавливаются внизу.

## Что уже работает

- Двойная буферизация, чтобы не мерцало
- Гравитация (у больших шариков сильнее)
- Отскок от стен и кубов с потерей энергии (коэф 0.85)
- Трение о пол
- 40 шариков разного размера и цвета
- 25 кубов, которые не пересекаются и не выходят за экран
- Выход по Esc

## Как запустить

Открыть .sln в Visual Studio, собрать, запустить. Всё.
